# 功能说明

[English](../en/requirements.md) | 简体中文

File Lock Inspector 在 IDE 中诊断本地 Windows 文件占用，支持查看占用进程、复制详情和结束所选进程。

## 诊断入口

- 主工具栏搜索按钮前的“锁与使用者”图标，悬浮提示为“查看文件占用”。
- **Tools > 查看文件占用**。
- 项目视图右键菜单中的“查看文件占用”，选中的文件会带入弹窗。
- 识别到的中英文 Gradle 文件共享冲突错误中的诊断链接。错误涉及多个文件时，AS 入口提供文件选择。

## 扫描与列表

选择文件或粘贴本地绝对路径后，点击刷新或在路径框中按 Enter 扫描。携带文件路径打开弹窗时自动扫描。路径支持空格和中文。

扫描在后台执行，结果逐条加入列表，显示进程名称、PID、所有者、启动时间和操作状态。表头支持排序，列表支持多选。扫描结束时，同一 PID、启动时间和文件身份的选中项保持选中。

取消扫描保留已经返回的结果，并显示取消状态。单次辅助程序执行时间限制为 30 秒。扫描期间路径框只读，刷新、文件选择和清空按钮不可用。

## 进程详情

选中进程后显示详情，支持多个进程同时查看：

| 信息 | 内容 |
| --- | --- |
| PID | 进程编号 |
| 可执行文件 | 程序完整路径 |
| 启动时间 | 进程创建时间 |
| 所有者 | Windows 账户 |
| 文件 | 本次诊断的目标文件 |
| 匹配依据 | 已打开文件句柄或已加载模块 |
| 命令行 | 可读取且进程身份匹配时显示 |
| 操作 | 可选择操作或受保护状态 |

详情区支持换行、滚动和文本选择。标题右侧图标复制全部已显示详情；右键菜单提供“复制此条信息”“复制所选文本”和“复制全部详情”。自动换行不影响单条信息的完整复制。

## 清空与历史结果

“清空结果”重置当前弹窗的列表、详情、选择和状态，保留文件路径，不删除文件或结束进程。

识别构建错误后，插件可在后台保存带时间的扫描结果。“历史查询结果”用于查看该文件已保存的诊断信息，历史结果不能用于结束进程。清空弹窗不删除项目保存的历史记录。

## 结束进程与重新构建

结束进程需要明确选择，并在确认对话框中确认。执行前重新核实进程启动时间、文件身份和当前占用情况。当前 IDE、辅助程序、关键进程及受保护或无法确认保护状态的目标不可通过此操作结束。

操作仅针对所选进程，不自动结束子进程；强制结束可能丢失未保存内容。插件等待退出结果后再次查询文件占用。

从构建错误入口打开弹窗且 IDE 提供唯一原构建重试动作时，显示“重新执行原构建”。构建由用户单独触发。

## 界面语言

在 **Settings > Tools > File Lock Inspector** 选择“跟随 IDE、中文、英文”。默认跟随 IDE：中文 IDE 使用简体中文，其他语言使用英文。选择保存在 IDE 级设置中，跨项目生效。路径、进程名称、命令行和原始构建日志保留原文。
