# 操作与状态

[English](../en/troubleshooting.md) | 简体中文

## 工具窗口

File Lock Inspector 默认位于右侧工具窗口栏。通过 IDE 的窗口菜单可切换停靠、浮动和独立窗口模式，也可移至其他边缘。窗口布局由 IDE 保存。

隐藏工具窗口会保留查询结果和正在执行的任务。关闭查询标签页会取消该页任务并释放资源。不同文件可在独立标签页中查询；再次打开已有目标会选中对应页，不会重新扫描，点击刷新可重新查询。窄视图下进程表格支持水平滚动。

## 工具栏

拖动进程列表与详情之间的分隔条可调整两区高度比例。鼠标悬停时分隔条高亮，并显示上下调整光标。调整后的比例会被记忆；详情隐藏时列表占满可用空间。

| 操作 | 行为 |
| --- | --- |
| 选择文件 | 打开 IDE 文件选择器，选择后开始扫描 |
| 刷新 | 扫描当前路径 |
| 取消扫描 | 结束本次扫描辅助程序，保留已返回的进程结果 |
| 清空结果 | 清空查询页显示并保留路径 |

取消按钮仅在扫描或进程操作期间可用。结束进程时，提示变为**取消后续操作**；已经提交的终止操作不会撤销。刷新、选择文件和清空在这些操作期间不可用。

## 查询状态

| 状态 | 含义 |
| --- | --- |
| 就绪 | 可以输入路径或开始扫描 |
| 正在扫描 | 后台查询中，结果逐条显示 |
| 扫描完成 | 既定扫描完成 |
| 部分扫描 | 存在跳过检查，返回可获取结果 |
| 已取消 | 用户取消执行，保留已返回结果 |
| 已超时 | 达到 30 秒执行限制，保留已返回结果 |
| 文件不存在 | 目标文件不可找到 |
| 权限不足 | 当前权限不足以完成查询或操作 |
| 无效路径或不支持目标 | 输入不符合本地单文件范围 |
| 无法确认身份 | 无法取得必要的文件或进程身份信息 |
| 无法准备或启动辅助程序 | 辅助程序无法提取或启动，详细原因记录在 IDE 日志中 |
| 辅助程序响应异常 | 辅助程序返回了非预期响应，详细原因记录在 IDE 日志中 |

状态栏显示查询时间、进程数量和跳过检查数量；悬浮可查看完整状态文本。空列表表示本次没有返回匹配进程。

## 进程操作状态

| 状态 | 含义 |
| --- | --- |
| 可选择并确认操作 | 支持选择并提交结束请求，执行前仍会核验 |
| 受保护进程或无法确认保护状态 | 结束操作不可用 |
| 进程身份已变化 | 不执行终止 |
| 未确认当前文件使用情况 | 不执行终止 |
| 进程已退出 | 目标已经结束 |
| 已确认进程退出 | 终止后观察到退出 |
| 已请求结束，尚未确认退出 | 五秒内未确认退出 |

操作完成后再次扫描并显示当前占用，操作结果显示在详情区。
